 Reflexión

Cuando probé textContent con <b>hola</b>, las etiquetas se mostraron tal cual. Con innerHTML, el navegador las interpretó y puso «hola» en negrita. Así vi que textContent muestra texto y que innerHTML también puede cambiar el formato. No usaría innerHTML directamente con texto que escribe una persona porque podría interpretar contenido que no esperaba. Para mostrar ese texto usaría textContent.
